How it works

Three motions. No app to switch to.

LauronFlow lives in the menu bar and never takes focus. It works inside whatever you're already typing in — Mail, Slack, a terminal, an address bar.

01 / HOLD
⌥

Hold Right Option

Anywhere, in any app. It's observed, not swallowed — your keystrokes still work normally.

02 / SPEAK
◕

Say what you mean

A small floating widget shows a live waveform so you know it's actually listening.

03 / RELEASE
↵

Let go

The transcript is typed instantly into whatever has focus. Misheard something? Undo with ⌃⌥Z.

Built for how you actually work

Small utility, full control

Every setting lives in one Settings window — General, Vocabulary, Shortcuts.

Custom vocabulary

Teach it the names and jargon it keeps mishearing — a find/replace list applied before anything is typed.

Configurable hotkeys

Change the push-to-talk key and the undo shortcut from Settings → Shortcuts. No restart needed.

Undo last dictation

One keystroke removes the last thing LauronFlow typed, restoring your original clipboard after.

Live waveform widget

A floating indicator confirms you're being heard while recording — toggle it off if you'd rather not see it.

Launch at login

One toggle, backed by SMAppService — it's ready before you are.

Parakeet, on-device

NVIDIA's Parakeet TDT model runs locally via Apple's MLX — loaded once, reused for every utterance.
